 🌱 Nosso Tema — AgroFlow IA

* **Problema:** filas de caminhões, rotas ruins, atrasos e desperdício de grãos.
* **Solução:** sistema web para melhorar a logística agrícola.
* **Funções:** acompanha caminhões, silos e rotas.
* **IA:** analisa informações e sugere melhores decisões.
* **Benefícios:** menos espera, combustível e desperdício; mais organização e economia.
* **Público-alvo:** cooperativas, transportadoras, silos e produtores.
* **Modelo de negócio:** assinatura mensal do sistema.

## 💻 Nosso Código

* **HTML:** cria a estrutura e as páginas do site.
* **CSS:** define o visual, cores, botões e organização.
* **JavaScript:** adiciona interações e funcionalidades.
* **Python:** pode ser usado no backend para processar os dados.
* **MySQL:** pode armazenar dados de caminhões, silos e rotas.

**Resumo:** 🚜 **AgroFlow IA = tecnologia + logística + inteligência artificial para tornar o agronegócio mais eficiente.**

# 🚀 Como Executar o AgroFlow IA

Siga os passos abaixo para configurar e executar o projeto em sua máquina local.

## 🛠️ Passo a Passo para Execução

### 1. Abrir o projeto
Abra a pasta do projeto **AgroFlow IA** no seu VS Code ou terminal de preferência.

### 2. Criar o ambiente virtual
No terminal, crie o ambiente virtual executando o comando:
```bash
python -m venv venv
```

### 3. Ativar o ambiente virtual
Ative o ambiente criado (comando específico para Windows):
```bash
venv\Scripts\activate
```

### 4. Instalar as dependências
Instale todas as bibliotecas necessárias listadas no arquivo de requisitos:
```bash
pip install -r requirements.txt
```

> 📦 **Principais bibliotecas instaladas:** Flask • Flask-CORS • Flask-SQLAlchemy • PyMySQL • Requests • Pandas • NumPy

### 5. Executar o sistema
Inicie o servidor do backend em Python:
```bash
python app.py
```
*Após executar, abra no seu navegador o endereço local informado no terminal (ex: `http://127.0.0.1:5000`).*

### 6. Encerrar o ambiente virtual
Quando terminar de trabalhar no projeto, você pode desativar o ambiente virtual com o comando:
```bash
deactivate
```
